# Version 0.0.1 — June 16, 2026

## Item Management (Items)
- Support for **sizes** and **variants (add-ons)** when adding and editing items
- Display size and add-on counts on the item card (ItemCard)
- New **CategorySearchSelect** component — dynamic category search instead of a static list
- Dynamic search used for the category filter on the items page
- Improved edit experience: fetch item data from the API with a loading state
- Refresh the list when clicking the same link (same-route refresh)

## AI Menu Import
- Improved bulk-save payload building to support sizes and variants
- Separate Arabic / English fields for add-ons in the review step
- **Retry** button in the save result panel on failure
- Improved save result summary (category and item breakdown)

## Dashboard
- Upcoming features announcement with a **countdown** (e.g. delivery orders)
- **View Menu** button in the sidebar to open the public menu in a new tab

## Admin Panel
- Revenue display formatted in EGP via `formatMenuPrice`

## Advertisements & Links
- Normalize external ad URLs (`normalizeExternalUrl`) — support links starting with `www.`
- Improved URL validation in the advertisement schema

## Authentication
- **Register with Google** on the registration page via `GoogleSignInButton` (same flow as login)

## Technical Improvements
- **Safe Navigation Guard** — prevent full reload when clicking the same page and refresh data instead
- New `useSameRouteRefresh` hook to refresh the page on same-route navigation
- Improved `useSafeRouter` to support the same behavior
- CSS styles for react-select filters (filter-select)
- Improved reCAPTCHA appearance on the login page
- Localization updates (Arabic / English)
